🚗 WhatNext Vision Motors:
 Shaping the Future of Mobility with Innovation and Excellence:
 WhatNext Vision Motors is a Salesforce-based Automotive Dealership Management System developed to manage vehicles, customers, dealers, vehicle orders, test drives, and    service requests in a centralized CRM platform.
 The project uses Salesforce DX, Apex, Triggers, Salesforce Flow, SOQL, custom objects, relationships, reports, and dashboards to automate dealership operations and improve  data management.

📌 Project Overview

Automobile dealerships need to manage different types of information such as:

Vehicle details
Vehicle stock
Customer information
Dealer information
Vehicle orders
Test drives
Service requests

Managing these activities manually can lead to data duplication, incorrect stock information, and delays in processing orders.
WhatNext Vision Motors provides a centralized Salesforce application to manage these operations efficiently.

🎯 Objectives

The main objectives of the project are:

Manage vehicle information and inventory.
Maintain customer records.
Maintain dealer information.
Manage vehicle orders.
Validate vehicle stock before confirming an order.
Automatically update vehicle stock.
Manage test-drive requests.
Manage service requests.
Automate repetitive business processes.
Generate reports and dashboards for better visibility.

🚀 Getting Started
Step 1: Clone the Repository
git clone <your-github-repository-url>
Step 2: Open the Project
cd WhatNext-Vision-Motors

Open the folder in Visual Studio Code.

Step 3: Login to Salesforce
sf org login web

A browser window will open. Log in using your Salesforce credentials.

Step 4: Check Authorized Orgs
sf org list

This displays the Salesforce orgs authorized with your CLI.

Step 5: Open Salesforce Org
sf org open
Step 6: Deploy the Project

Deploy the Salesforce metadata:

sf project deploy start
Step 7: Retrieve Changes

If you make changes directly in Salesforce and want to retrieve them:

sf project retrieve start
